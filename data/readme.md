<h1> Data Directory Overview</h1>
<br>
This is an overview of the data sources used for this research. <br>
<br>
<li> analysis directory</li> 
The analysis directory contains controlled packet captures and tasking metadata files used to analyze client and servrer encrypted data exchange. <br>
<li>training directory</li>
The training directory contains the files used to train the model. <br>

<li>testing directory</li>
The testing directory contains the files used for model validation. <br>
<hr>
Please note that only the C2 data is in this repository.  The benign files were drawn from the Cipher Spectrum data set and can be obtained there.

https://cgi.cse.unsw.edu.au/~cspectrum/
